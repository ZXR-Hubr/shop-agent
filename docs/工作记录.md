# 工作记录 · 电商智能客服 Agent（shop-agent）

## 2026-11-17

- 路径：`E:\shop-agent`（全部代码、数据、虚拟环境都在 E 盘，C 盘无任何残留）
- 目标：把简历中「电商智能客服 Agent」项目做成可运行 Demo，用于开发者讲解。
- 技术选型：FastAPI + httpx（OpenAI 兼容接口） + 原生 HTML/JS；手写 Function Calling 循环，不引入 LangChain。
- 核心实现：
  - `app/agent.py`：system prompt + 多轮记忆 + 工具调用循环（最多 5 轮）
  - `app/tools.py`：search_products / get_order / create_after_sales / search_faq
  - `app/rag.py`：本地字符 bigram 哈希向量（512 维）+ 余弦 Top-K，可选远程 embedding
  - `app/memory.py`：session 记忆（内存 / 可选 Redis）
  - `app/llm.py`：真实 API + 无 Key 自动 Mock
  - `app/main.py`：FastAPI 入口，`/api/chat`、`/api/health`、`/api/session/{id}/reset`
- 环境：依赖装在 `E:\shop-agent\.venv`（Python venv），不使用系统/工具自带 Python 的 site-packages。
- 验证结果：pytest 19 passed；eval 10/10（mock）；uvicorn 8000 端口端到端通过。
- 备注：简历中的 LangChain/Coze、pgvector/Milvus 在 Demo 中为等价实现，讲解文档已注明边界，避免夸大。
- 文档：`README.md`、`docs/开发者讲解.md`。
